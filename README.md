# Joyisfree

Tracks that live outside the studio app (`joyisfree/joyisfree1`). Each track has its own folder, its own `docs/state.md`
and its own ledger, and none of them touches the studio.

- [`galxe-desk/`](./galxe-desk/README.md): the Galxe Desk. A specialist team, the official rulebook read and kept, a Prize
  Gate that refuses worthless or unclaimable quests, and a 90-day by-hand run with a ledger and kill rules. Started
  28 Oct 2026 from Leif's braindump, after three research scouts and three independent crypto reviewers.

No dependencies: `npm test` runs on Node 22 alone.
